一个品牌，连接四种能力。

DATA & TECHNOLOGY

可信的数据，从明确的边界开始。

01

真实来源

每次采集验证城市、日期、关键词与酒店身份。广告保留并标记，历史失败与部分完成如实留存。

02

统一数据入口

统一 API、Cloudflare D1 与已有任务调度。标准酒店映射保持身份稳定，历史观察保持原样。

03

远程可诊断

设备心跳、任务执行记录、错误与结构化云端日志，让排错不必站在采集电脑旁。

USE CASES

贴近每天发生的经营问题。

晨间市场观察

查看今天与未来入住日的真实竞品价格，辨别采集时间和数据缺口。

经营复盘

导入经营表格，拆解房型和渠道表现，比较营收、房量与均价。

采集运维

在设备页查看最近任务、失败原因和运行日志，再决定是否需要现场处理。

安装与已有设备升级
  1. 解压下载包，在 Chrome 扩展管理页打开开发者模式。
  2. 新设备使用“加载已解压的扩展程序”，选择解压目录。
  3. 已有设备将文件覆盖到原扩展目录，再重载扩展，保留设备身份和本地状态。
  4. 新设备须在 OTA 设备页获管理员批准后接单；任务由云端创建。

Windows 新域名与真实采集最终验收尚待办公室设备验证。
